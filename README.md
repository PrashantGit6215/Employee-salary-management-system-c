# Employee Salary Management System in C

A basic Employee Salary Management System developed using C programming language.

## Project Description

This project is designed to manage employee information and calculate employee salaries.

It is a simple console-based application developed for learning basic C programming concepts.

## Features

- Add Employee Details
- View All Employees
- Search Employee by ID
- Calculate Employee Salary
- Display Salary Details
- Exit System

## Salary Calculation

- HRA = 10% of Basic Salary
- DA = 5% of Basic Salary
- PF = 12% of Basic Salary

Net Salary = Basic Salary + HRA + DA - PF

## Technologies Used

- C Programming
- Structure
- Array
- Switch Case
- Loops
- Conditional Statements

## How to Run

1. Download the source code.
2. Open it in a C compiler.
3. Compile the program.
